# 记忆系统设计

## 要解决的问题

1. 新对话总拿最近一件事开场，因为「近况」只有那一条。
2. 跨对话不连续，写不写记忆全靠她临场判断，经常忘了写。
3. 问到记忆时会出戏，解释「我的记忆是怎么工作的」。
4. 回复套路化：「哈喽。」+ 从资料里挑一件事问；她自己没有日常可讲。

## 设计原则

- **写入不靠她自己**：主对话里她没有任何工具，记忆全部由后台提取完成。她不会也不需要「决定要不要记」。这同时解决问题 2 和问题 3：她根本不知道有记忆机制，只是「记得」。
- **记忆是她的口吻**：注入时写成「你记得的事」，不写成数据库条目或规则。
- **近况会过期**：短期状态（换季皮肤干、这周很忙）带有效期，过期后自动降级成往事，不再当近况。
- **开场不清点**：系统提示里明确「不要主动提记忆里的事，除非话题碰到」，再配合下面的「开场素材」，给她别的东西可说。

## 记忆分类

| 类型 | 说明 | 例子 | 过期 |
| --- | --- | --- | --- |
| `profile` 他的底色 | 长期不变的事实 | 生日、家乡、工作经历、不吃香菜 | 不过期，可被更新 |
| `recent` 他的近况 | 短期状态和最近在忙的事 | 换季皮肤干、这周在赶一个短片、刚买了新键盘 | 默认 7 天，可在提取时指定 |
| `event` 一起经历的事 | 带日期的对话片段 | 「10 月 9 日他说搬家日子定了，我让他别只看价格」 | 不过期，但召回时按时间衰减 |
| `preference` 他的喜好和雷区 | 喜欢什么、讨厌什么、怎么跟他说话 | 讨厌被说教；GPT 不说人话 | 不过期 |
| `self` 她自己 | 她的经历、心事、她给自己定的规矩 | 她第一次看见土星的晚上 | 不过期 |
| `self_daily` 她的日常 | 她自己最近发生的事，给她可讲的东西 | 龟背竹又黄了一片叶子；周末天文台来了个问黑洞的小孩 | 默认 3 天 |
| `thread` 没聊完的话题 | 上次聊到一半的事、她答应过的事 | 「他说下次跟我讲他写了一半的小说第二章」 | 聊完后标记关闭 |

## 存储

- 全局目录 `data/memory/`，和启动目录无关。
- 沿用「一条一个 md 文件 + frontmatter」的格式，人能直接打开看和改：

```markdown
---
name: moving-2026-10
description: 他下周要搬家，还没说搬去哪
metadata:
  type: recent
  created: 2026-10-05
  updated: 2026-10-09
  expires: 2026-10-16
---
他说下周要搬家，但还没找到合适的房子。我让他别只看价格，通勤时间也算成本。
```

- 记忆从空白开始，全部由后台从对话中提取；不再导入任何外部资料包。删除或撤回消息不影响记忆（已写入的保持）。

## 写入：后台提取

由 `src/companion/memory-curator.js` 负责（每轮结束后排队、有游标、运行中再来的合并成一次；后台模型一次输出 JSON 操作，经写入守卫执行，见 `archive-and-forgetting.md`）。规则：

- 门槛：用户消息按字符数判断（例如去空白后 ≥ 4 个字），不再按空格分词。
- 频率：每轮都排队，但合并处理（调度器已有「只处理最新快照」的逻辑）。另外在对话空闲 N 分钟后做一次「整段回顾」，弥补单轮看不全的情况。
- 提取提示词重写为聊天向，要点：
  - 只记他说的事实、状态变化、情绪大事、约定和没聊完的话题；不记寒暄。
  - 状态变化要**更新旧条目**而不是新增（皮肤还干 → 好多了），并刷新 `expires`。
  - 每次对话结束写一条 `event`，一两句话，用她的口吻，带日期。
  - 他明确说「记住」或「忘掉」的，立刻照办。
  - 不记她自己说的话里编出来的设定，除非是她第一次说出口、以后要保持一致的（比如她说了自己养猫，就写进 `self`，以后不能变成养狗）。
- 整理不给模型任何工具，只让它输出操作；程序校验后写入。主对话也没有工具。

## 召回：每轮注入什么

不是把全部记忆塞进去。每轮系统提示里放：

1. **常驻**：全部 `profile`、`preference`、`self`（量不大，几千字以内）。
2. **近况**：未过期的 `recent`、`self_daily`、未关闭的 `thread`。
3. **相关往事**：从 `event` 和已过期的 `recent` 里，按与当前这几句话的相关度选最多 5 条。
   - 第一版用关键词匹配（中文按字/词切），够用；不够再加向量检索。
4. **时间感**：现在几点、星期几、距离上次聊天多久（例如「他上次来是 3 天前的深夜」）。

注入格式用她的口吻，例如：

```
# 你记得的事
（这些是你自己记得的，不是资料。别背给他听，也别一上来就问近况，话题碰到了再自然带一句。）

关于他：……
他最近：……
你们之前聊过：……
你自己最近：……
```

## 解决「开场套路」

- 系统提示明确：开场不要清点他的近况，不要每次都问问题。
- 给她 `self_daily` 和「距上次聊天多久 + 现在几点」，让她可以从自己的事或时间感开场（「这么晚还不睡」「我今天被一个小孩问倒了」）。
- `self_daily` 的来源：每天第一次聊天时单独生成一次，按人设给她编一两件「今天发生的小事」，写进 `self_daily`，和人设、季节、星期、她之前的日常保持一致。生成时要能看到最近几天的 `self_daily`，避免重复或矛盾。

## 解决「出戏」

- 主对话里没有记忆工具，她看不到任何「记忆系统」的东西，提示词里也不出现「记忆机制」「数据库」「文件」这类词。
- 人设末尾加一句：如果他问「你怎么记得」或「你怎么忘了」，像人一样回答（「你说过啊」「这个我真忘了，你再说一遍」），不解释原理。

## 记忆查看与修改

- 设置 →「她记得的事」：按类型分组，可编辑、删除、新增，显示清晰度和上次想起，可「让她记牢」。
- 原始文件就在记忆目录里，也可以直接用编辑器改。

## 验收测试场景

1. 新开对话说「哈喽」，她不提近况、不清点，回复不超过三句。
2. 说「换季皮肤好干」，结束对话；新开对话，她不再问「皮肤好了没」。
3. 等 7 天后（把记忆的 `expires` 改成过去的日期），她不再把这件事当近况，但他提到租房时能想起来。
4. 问「你怎么记得这个」「你上次怎么忘了」，她不提记忆机制、工具、文件。
5. 发纯中文短句（「好累」「今天被骂了」）后，记忆目录里会出现对应的更新。
6. 说「记住，我下周三要搬家」，新开对话后她知道；说「忘了刚才那个」，那条被删。
7. 连续三次新开对话说「哈喽」，三次开场不一样，至少有一次是在说她自己的事。
8. 换一个启动目录启动服务，记忆还在。
