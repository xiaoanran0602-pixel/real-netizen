# 模型调校与设置

## 目标

她像在微信上随手回消息：快、直觉、口语，不像深思熟虑后交的答卷。所有可调的东西都收进「设置」，聊天界面上一个技术控件都不出现。

## 模型接入的默认值

| 项 | Lin 默认 | 说明 |
| --- | --- | --- |
| 网关 | 任意 Anthropic Messages 兼容网关（也支持 OpenAI 兼容） | 设置 →「模型」 |
| 模型 | `claude-opus-4-6` | |
| 推理强度 | **low** | 见下方实测 |
| 思考方式 | `thinking: {type: "adaptive"}` + `output_config.effort` | 这个模型只能这样控制，见下方 |
| 最大输出 | 2048 tokens | 自适应思考的 token 也算在里面，low 档思考很短，2048 足够一段聊天回复 |
| 温度 | 不设置（用模型默认） | adaptive 思考下温度可能不可调，先不碰 |
| 回复出现方式 | 整段出现 | 设置 →「聊天」可改逐字出现 |
| 后台记忆提取 | 单独的模型和强度，见下方 | 不影响聊天手感 |

### 实测记录（直连网关，简版人设）

**关不掉思考**：`thinking: {type: "disabled"}` 被拒，报错原话是「disabled is not supported for this model. Use adaptive and output_config.effort to control thinking behavior」。所以只能用 adaptive + effort 调低，不能彻底关。

**effort 对比**：

| 问题 | low | medium | high |
| --- | --- | --- | --- |
| 「我今天好累啊」 | 3.9 秒，97 tokens | 3.0 秒，93 tokens | 3.5 秒，95 tokens |
| 「你觉得我 35 岁前还能拿到电影导演的机会吗」 | 5.8 秒，177 tokens | 7.6 秒，246 tokens | 6.4 秒，311 tokens |

- 闲聊时三档差不多，模型自己判断不需要想。
- 认真的问题上，low 回复更短、更快；high 会写得更长、更像分析。low 更接近「直觉型聊天」。
- 单次测的延迟有网络波动，只能看趋势。
- 三档的回复都有点「客服式关心」（「喝口热水」「我在听」）。这是人设和记忆的问题，不是推理强度的问题，靠完整人设和记忆系统解决。

### 程序里怎么落地

- `src/model/anthropic.js`：`reasoningLevel` → `{"thinking": {"type": "adaptive"}, "output_config": {"effort": reasoningLevel}}`，正好是实测可用的格式；设为 `off` 时不带思考参数。网关对 `output_config` 报 400 时自动去掉思考参数重试一次。
- OpenAI 兼容协议映射成 `reasoning_effort`。
- 聊天默认 `low`，后台默认 `medium`；最大输出映射成 `max_tokens`。

### 后台记忆提取用的模型

- 已定：`claude-sonnet-4-6`，effort `medium`。提取要准确，不追求速度，也不影响聊天手感。
- 每天第一次打开时生成「她的日常」也用这个模型。
- 已实现：设置 →「模型」里单独填后台模型；后台模型失败时退回聊天模型重试一次。

## 界面上不出现的东西

编程工作台聊天输入框附近常见的控件，Lin 里全部不出现：

| 控件 | 原位置 | Lin |
| --- | --- | --- |
| 推理强度（思考强度）选择 | 输入框工具条 | 不出现，在设置里 |
| 权限模式（完全访问 / 询问 / 只读等） | 输入框工具条 | 删除（她没有工具，权限无意义），设置里也没有 |
| 计划模式勾选 | 同上 | 删除 |
| 模型选择 | 输入框工具条 | 不出现，在设置里 |
| 附件、@ 引用、/ 命令 | 输入框 | 删除 |
| 上下文用量、Token、费用 | 状态面板 | 不出现，在设置的「高级」里可看 |
| 工作区、项目选择 | 空对话页 | 删除 |
| 停止生成按钮 | 输入框 | 删除 |

Lin 的聊天页只有：顶栏（名字、「对方正在输入…」）、消息区、输入框、发送按钮。

## 设置页

所有能调的都在这里，入口在底部导航「我」→「设置」。分组如下：

### 她

- 名字：林澈
- 头像：上传图片，或用默认色块（`#7c6fb0` + 「林」字）
- 签名：一句话，显示在她的资料页
- 人设：大文本框，编辑 `data/core.md`，保存后下一句话生效
- 她怎么称呼你：（默认留空，她会用「他」）

### 她记得的事

- 按分类列出记忆（他的底色、他的近况、你们聊过的、她自己、她的日常、没聊完的话题），可查看、修改、删除、新增单条。
- 近况条目显示剩余有效期，可以手动延长或标记已过期。
- 导入 / 导出（从 JSON 文件导入记忆）。

### 你

- 你的名字、头像

### 聊天

- 回复出现方式：整段出现（默认）/ 逐字出现
- 「对方正在输入…」前的停顿：开（默认）/ 关
- 一次回复拆成多个气泡：开（默认）/ 关
- 回复长度上限：短（1024，默认）/ 中 / 长
- 开始新对话：新开一条对话，旧的保留可翻看；记忆是全局的，不受影响
- 以前的对话：列表，点进去只读查看

### 模型

- 服务地址：`https://api.openai.com/v1`（或任意兼容网关）
- API Key：只显示后四位
- 模型：从网关的模型列表里读取，或手动填写
- 推理强度：low（默认）/ medium / high，旁边一句说明「越高越深思熟虑，回复越慢越长；low 更像随口聊天」
- 记忆提取模型和强度
- 测试连接按钮

### 外观

- 主题：浅色 / 深色 / 跟随系统
- 字号
- 聊天背景色（可选）

### 在手机上打开

- 二维码、局域网地址、端口
- 重置访问令牌

### 数据

- 导出聊天记录（文本 / Markdown）
- 导出记忆（ZIP）
- 数据目录位置
- 清空聊天记录（二次确认）

### 高级（默认折叠）

- 上下文用量、累计 Token
- 调试日志开关
- 对话 ID、数据目录、她的内心（只读调试面板）

## 设置存在哪

- 统一放在 `Lin/data/` 下：`settings.json`（聊天、外观、推理强度等）、`core.md`（人设）、`memory/`（记忆）。
- 模型地址和 API Key 单独存在 `data/secrets/model.json`，不进 `settings.json`，`lin.ps1 -Pack` 打包时不包含。
- 设置改了立即生效，不用重启服务。人设和模型参数从下一句话开始生效。

## 验收

1. 聊天页上找不到推理强度、权限模式、模型选择、附件、停止按钮。
2. 不改任何设置时，实际发给网关的请求是 `effort: low`、`max_tokens: 1024`（看调试日志）。
3. 在设置里把推理强度改成 high，下一句话的请求变成 `effort: high`。
4. 在设置里改人设（比如加一句「你最近在学吉他」），下一句话她就知道。
5. 在设置里删掉一条记忆，她之后不再提这件事。
